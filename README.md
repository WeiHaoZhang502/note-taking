# 智能学习平台

一个现代化的在线学习网站，集成AI助手功能，帮助用户高效学习。

## 功能特性

✨ **核心功能**
- 📚 课程管理系统
- 👤 用户认证与个人资料
- 📊 学习进度跟踪
- 📝 作业与测试系统
- 💬 AI智能助手
- 🎯 个性化学习推荐
- 📈 学习统计与分析

## 技术栈

### 前端
- Vue 3
- TypeScript
- Vite
- Tailwind CSS
- Axios

### 后端
- Node.js
- Express.js
- MongoDB
- JWT 认证
- Socket.io（实时通讯）

## 项目结构

```
learning-platform/
├── frontend/          # Vue 3 前端应用
├── backend/           # Express 后端应用
├── docs/              # 文档
└── docker-compose.yml # Docker 配置
```

## 快速开始

### 前提条件
- Node.js 16+
- npm 或 yarn
- MongoDB 4.4+

### 安装与运行

#### 后端
```bash
cd backend
npm install
npm run dev
```

#### 前端
```bash
cd frontend
npm install
npm run dev
```

#### 使用 Docker
```bash
docker-compose up
```
